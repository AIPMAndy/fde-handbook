# FDE 岗位研究与原创课程映射

核查：2026-11-25。原始 [伙伴路径](https://anthropic-partners.skilljar.com/path/claude-fde) 无法直接访问；以下课程映射基于 [第三方课程结构报道](https://fdeinterviews.com/blog/anthropic-claude-forward-deployed-engineer-learning-path)，不是原课件复刻。[Frontier Academy](https://www.anthropic.com/news/claude-frontier-academy) 是另一套机构提名与实践考核体系。本项目不提供认证。

| 样本 | 主要交付责任 | 应准备的证据 |
|---|---|---|
| [Anthropic](https://job-boards.greenhouse.io/anthropic/jobs/5391016008-9) | 客户环境应用开发、MCP/Skill 组件、可复用部署模式 | 安全工具接口、模型评测、客户交接 |
| [OpenAI](https://openai.com/careers/forward-deployed-engineer-%28fde%29-sf-san-francisco/) | 从 discovery 到 rollout、业务影响和评测反馈 | 试点计划、系统设计、可运行实现、效果与上线证据 |
| [Palantir](https://jobs.lever.co/palantir/636fc05c-d348-4a06-be51-597cb9e07488/) | 在客户场景中实施 GenAI 工作流 | 数据模型、系统接入与持续运营方案 |
| [Accenture](https://www.accenture.com/us-en/careers/jobdetails?id=R00352354_en)（历史岗位样本） | 行业集成、数据工程、端到端交付 | 数据管道设计、客户需求文档、变更及验收 |

高级岗位往往要求成熟工程经验。学习完成不等于达到高级岗位要求；申请前重新核对实时 JD。

公开案例：[What FDE means at OpenAI](https://openai.com/index/forward-deployed-engineering-means/)。供应商披露不是独立审计；学习重点是业务验收、真实失败反馈、可复用组件。不把供应商指标当作项目业绩。

独立研究审查：官方岗位和公开方法为较强证据，伙伴课程主题来自第三方报道，原课程细节未核实；课程与就业结果、实际企业 ROI 尚未做真实验证。
