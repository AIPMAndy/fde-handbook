## 实战案例

## 案例 A｜售后政策助手（可运行）

教学模拟 · 已提供离线代码

**问题：**客服查找政策耗时，且不同角色可以访问的政策不同。

**基线：**教学假设：人工 6 分钟/单；每月 1,000 单。不是实测。

**范围：**只读政策检索、证据引用、无证据拒答；不自动退款。

**数据：**lab/knowledge.json 合成数据；无真实客户信息。

- 运行 python -m lab.fde --question "退款期限" --role agent。
- 用 manager 角色访问内部补偿政策，再用 agent 重试，验证权限差异。
- 运行 python -m lab.evaluate；添加一条自己的合成测试。
- 若使用真实 Claude，单独记录模型版本、人工审核结果与费用；不得上传真实客户资料。**验收：**本地评测全部通过；真实试点由客户另行确认目标（示例：6→4 分钟/单，质量不下降，零越权）。

**局限：**关键词检索有召回局限；CLI 角色不是身份认证；没有生产后端、工单集成或实际客户验证。

## 案例 B｜采购合同预审（方案型）

教学模拟 · 需自行实施

**问题：**采购人员手工比较合同条款，遗漏非标付款条件。

**基线：**教学假设：20 分钟/份；基线需用同一批脱敏合同独立测量。

**范围：**从合成合同提取条款并对照采购规则；只给风险提示，不作法律判断或签约。

**数据：**自建五份合成合同，含缺失付款条件、冲突条款、越权供应商、注入文本。

- 定义条款提取 schema：source_id、page、clause、risk、reason。
- 做规则基线与模型提取对照；缺页必须拒绝给出结论。
- 由采购和法务人员对留出样本标注并复核。
- 设计人工签字门禁和只读审计记录。**验收：**字段可追溯至原文；严重风险漏报和越权均为阻断项；业务阈值必须在真实试点前约定。

**局限：**真实合同可能含商业秘密；不得上传未经批准的材料。当前无真实执行结果。

## 案例 C｜企业 IT 服务台（方案型）

教学模拟 · 需自行实施

**问题：**内部员工反复查询 IT 手册和申请进度。

**基线：**教学假设：每周 300 张请求；真实重复比例需采样测量。

**范围：**员工自助查询、自动分流建议；不执行账号开通、权限变更或删除。

**数据：**合成工单标签、FAQ、角色授权表；模拟不存在的设备和注入。

- 访谈服务台与安全团队，列出允许查询的字段及身份来源。
- 将 FAQ 与工单状态读取分成两个只读工具。
- 用未知工单、跨员工请求、过期政策、伪造身份测试。
- 小批用户试点，保留人工工单入口，监测回退比例。**验收：**仅返回已授权数据；无证据时转人工；每个动作可追溯；目标与基线由真实客户确认。

**局限：**身份映射、数据新鲜度、隐私与值班责任需生产验证；当前仅方案。

## 案例 D｜制造业质量问题分流

教学模拟 · 方案型

**问题：**一线人员提交缺陷描述，工程师分类并决定升级。

**基线：**待现场测量；不提供虚构产线指标。

**范围：**只建议缺陷分类和证据；不控制生产设备。

**数据：**合成缺陷描述、产品线、规则与例外。

- 定义类别与 unknown，标注 30 条合成记录。
- 对规则与模型做分层评测，单独记录高严重度漏判。
- 给每类设人工升级路径，模拟班次采用。**验收：**严重缺陷不得因模型被自动关闭；质量团队确认阈值。

**局限：**现场质量标准、设备集成和数据尚未实测。

## 案例 E｜销售知识与报价草稿

教学模拟 · 方案型

**问题：**售前查找产品规则、撰写报价耗时。

**基线：**真实耗时、错价和赢单归因均待测。

**范围：**仅授权文档读取与报价草案；不承诺折扣或发送客户。

**数据：**模拟产品目录、角色价格权限和历史询问。

- 识别公开、内部、受限价格字段。
- 设计引用、有效日期、拒答与人工审批。
- 记录报价生成时间、错误和复核时间，与人工基线比较。**验收：**不越权、不自动发送、不捏造报价；合格草稿率达到预先约定目标。

**局限：**真实商务条款必须人工审核；无真实成交证据。

## 离线实验：5 分钟启动

先下载或克隆源码，安装 Python 3.10+，在项目根目录运行。不需要 API key。

python -m lab.fde --question "退款期限" --role agent
python -m lab.evaluate
python -m unittest discover -s tests -v离线示例只是确定性检索与权限教学，不能证明真实模型质量或企业生产安全。可选 API 适配见 README。
