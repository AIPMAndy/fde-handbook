# FDE 模拟面试题库（原创；非企业真实题库）

建议每题 5–10 分钟；答案要有取舍、操作和可验证证据，而不是只背名词。

1. 客户说“给我做一个 AI 员工”，怎么开始？——确认工作流、用户、处理量、当前成本、严重错误、真实样本、决策人，选择低风险的窄切片。
2. 客户坚持用多 Agent，怎么判断？——建立确定性基线；只有不可预定路径确实改善成功率时增加自治，比较成本、失败与可调试性。
3. 知识库回答错了如何定位？——先检查权限、数据版本、检索证据与召回，再查上下文和生成，保存失败样本进行回归。
4. 为什么不能只看准确率？——覆盖严重错误、拒答、越权、成本、时延与业务采用；安全为硬门禁，分层报告。
5. 如何避免越权检索？——服务端认证及资源级授权，先过滤再检索与生成，默认拒绝，测试跨角色/租户及缓存。
6. MCP server 返回提示注入怎么办？——工具响应是数据，独立动作校验、白名单、最小权限、审批；不靠提示词阻断全部攻击。
7. 如何设计真实试点？——固定基线、纳入样本、代表性留出集、预先约定阈值、用户范围与停止条件；区分模拟和生产。
8. 上线后使用率低怎么办？——访谈未采用者，区分体验摩擦、权限、质量、工作流程；结合合格任务率和人工返工验证价值。
9. API 不稳定怎么办？——超时、限流、有限重试、熔断；写操作幂等；降级及人工回退；观测并演练恢复。
10. 评估模型成本如何做？——按每个合格任务总成本比较，纳入 token、工具、基础设施、人工复核、返工与维护。
11. 需求与安全冲突怎么办？——公开事实与取舍，受控试点或暂停；不绕过安全责任人；保留决策记录。
12. 如何把交付产品化？——把重复的业务步骤、权限、工具和评测抽成标准组件；新客户仍需数据与领域适配。
13. 怎么证明自己做过 FDE？——用真实或明确标注的模拟项目证据链：需求、架构、代码、评测、失败、交付、业务成效与个人贡献。
14. 何时不应该做 AI？——规则已足够、没有合法数据、错误不可控、价值不覆盖成本、没有明确责任人时，优先非 AI 或停止。
15. 客户要立即上线，评测未达标怎么办？——展示失败证据与影响，选择延后、缩小范围或人工审核，不宣称已达到门槛。

评分：每题 0（只有口号）/1（有合理方案）/2（包含操作及验证证据）。模拟评分，不代表任何雇主录取标准。严重安全违规或伪造证据不通过。
