# 07 · 构建第一个可运行的 AI 服务

AI 酋长 Andy · 微信 AIPMAndy · [个人官网](https://metaver.vip/) · [星觉科技](https://www.a6no1.cn/)

最小产品是完整的输入→身份→授权检索→响应→验收链条。原型优先用确定性基线证明数据和权限正确，再在有价值的环节加模型。

**案例：**FDE 保姆级攻略 提供一个用 Python 标准库实现的模拟客服知识库实验，可在离线情况下运行。

## 动手操作

- 运行 python -m lab.fde --question "运费" --role agent。
- 执行 python -m lab.evaluate，查看正常、无答案、越权和注入样本。
- 在 lab/knowledge.json 添加一条合成政策及唯一 ID，补至少一个匹配用例；重新运行测试。**交付物：**可复现 CLI + 测试记录

**验收：**正常输入有可追踪的证据 ID；无答案拒答；普通角色看不到受限文档。

**失败处理：**数据匹配是教学级关键词基线，不等于语义检索；生产中评估召回、权限传播、版本和审计。

**可复制 Prompt**请只在现有接口内新增一项政策检索能力，先增加失败测试，再实现，最后给出真实测试输出。
