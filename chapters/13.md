# 13 · 企业 API、认证、集成与幂等

AI 酋长 Andy · 微信 AIPMAndy · [个人官网](https://metaver.vip/) · [星觉科技](https://www.a6no1.cn/)

企业集成需要服务端认证、资源授权、输入 schema、请求追踪、超时、限流和幂等。开发环境与生产环境分离。不要把 CLI 模拟角色当真实身份。

**案例：**模拟内部服务台读取工单；跨员工查询必须拒绝。

## 动手操作

- 用 templates/tool-contract.md 定义 API 的方法、路径、输入、响应、身份来源、拒绝条件。
- 为 POST 提交草稿定义幂等键，重复请求返回相同结果；先做无副作用演练。
- 用 mock 模拟超时、401、403、429、5xx，定义有限重试、人工回退和审计字段。**交付物：**接口规范 + mock 测试记录

**验收：**每个错误都有明确行为；服务端身份可信；不可重试的写入不会重复执行。

**失败处理：**只有 HTTP 200 但业务状态错误时，增加领域校验，不吞掉异常。

**可复制 Prompt**审查 API 合同的身份、授权、幂等和失败恢复，给出逐项可执行的合成测试。
