# 23 · FDE 作品集与面试实战

AI 酋长 Andy · 微信 AIPMAndy · [个人官网](https://metaver.vip/) · [星觉科技](https://www.a6no1.cn/)

FDE 作品集应体现从模糊需求到可复现工程、业务验收和组织采用的证据链。演示代码只能证明你构建了原型，不代表客户真实上线。

**案例：**选择客服、企业采购或 IT 服务台的教学案例，按 45 分钟限时面试完成方案并解释取舍。

## 动手操作

- 从 cases 中任选一例，10 分钟澄清问题，15 分钟设计，10 分钟评测安全，10 分钟交付演示。
- 准备一页架构图、运行说明、至少五条测试、风险与回退方案。
- 复盘自己如何改变客户工作流；把真实数据与教学假设分开，不伪造项目结果。**交付物：**作品集 README + 5 分钟演示脚本 + 面试评分表

**验收：**别人可按步骤运行；能解释“不做什么”；明确哪些指标已测、哪些是假设。

**失败处理：**只展示模型回复而缺少工作流和验收时，补齐基线、权限和人工接管。

**可复制 Prompt**扮演客户和面试官：依次挑战需求、架构、评测、安全、成本、上线采用；每次只提一个问题并指出证据缺口。
