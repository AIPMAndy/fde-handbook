AI 酋长 Andy · 微信 AIPMAndy · [个人官网](https://metaver.vip/) · [星觉科技](https://www.a6no1.cn/)

FDE 必须能读懂输入输出、执行日志、版本与网络错误。零基础应先掌握函数、JSON、异常、HTTP 状态和 Git diff；不需要先学完全部算法。

**案例：**在 Mac 或 Windows 本地运行本仓库，完成一次可复现的小改动。

## 动手操作

- 安装 Python 3.10+；终端执行 python3 --version（Windows 可用 py -3）。解压并进入项目目录。
- 运行 python3 -m unittest discover -s tests -v；若无 python3 改用 python 或 py -3。
- 新建 Git 分支；修改合成政策文本并新增对应测试，运行评测，使用 git diff 查看变更。**交付物：**环境版本、运行记录、一个小补丁

**验收：**新环境无需 API key 就能完成本地测试；代码和数据修改可追踪。

**失败处理：**ModuleNotFoundError 优先检查当前目录和解释器；不要通过全局安装陌生依赖掩盖问题。

**可复制 Prompt**根据这份终端错误日志定位最小复现步骤，先说明如何检查版本、工作目录和依赖，再修复。
