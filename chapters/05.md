AI 酋长 Andy · 微信 AIPMAndy · [个人官网](https://metaver.vip/) · [星觉科技](https://www.a6no1.cn/)

把模型当作具有输入输出边界的组件。区分模型请求、上下文长度、工具权限、服务端错误及客户端超时。密钥只能在后端保存；版本和费用随供应商变化。

**案例：**在本地知识库读取政策，用同一组输入测试纯检索基线与可选 Claude API。

## 动手操作

- 运行 python -m lab.fde --question "退款期限" --role agent，查看证据 ID。
- 阅读 lab/fde.py 的 optional_claude 函数，确认只传允许访问的证据。
- 如已有 API 权限，按 README 设置 ANTHROPIC_API_KEY 与 CLAUDE_MODEL，再显式使用 --live；保留匿名输出和失败日志。**交付物：**本地基线记录；可选真实 API 试验记录

**验收：**无密钥也可运行基线；API 失败不伪造成功；不在前端或仓库写入密钥。

**失败处理：**401/403 检查账号权限及密钥；429/5xx 限制重试并报告；不要绕过配额。

**可复制 Prompt**审查这段 API 调用的数据、密钥、超时与错误处理；只用合成数据测试，未执行的请求不要声称成功。
